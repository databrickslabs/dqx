# Styling

  <AvailableSinceVersion version="0.17.0" heading={false} />

Admins can brand DQX Studio for their company under **Settings → Styling**. Changes apply to every Studio user as soon as they're saved. Users still choose light or dark mode themselves.

## Company Name

Adds your company to the top bar: **DQX Studio | Acme**. Leave it empty to show **DQX Studio**.

## Custom Logo

Replaces the DQX icon in the top bar. Use one logo for both modes, or separate logos for light and dark mode. Choose separate logos if your logo is hard to see on a dark header. Logo changes apply straight away.

- PNG, JPEG or WebP, up to 256 KB. SVG isn't supported: export your logo as a PNG or WebP instead.
- Logos are shown 24 px tall and up to 160 px wide, keeping their proportions. A logo about 200 px tall is plenty.
- With separate logos and no dark mode logo uploaded, dark mode shows the light mode logo.

## Branding

Pick a preset or set five colours: **Header**, **Page background**, **Text**, **Brand** and **Sidebar**. Studio derives the rest (cards, hover, borders, button text) from them.

- Dark mode is generated from your light colours automatically. Turn off **Generate dark mode from light colours** to set dark colours yourself. Presets set their own dark mode colours.
- If a colour combination may be hard to read, Studio shows a warning that names the colour to adjust. You can still save.
- Status colours (pass, warn, fail) and chart colours don't change.
- **Reset all styling to DQX Default** removes the company name, logo and colours for everyone. This can't be undone.

Presets: DQX Default, Databricks, Aubergine, Ocean, Dimmed, High contrast, Nord, Solarized and Dracula.
