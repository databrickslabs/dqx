# Marketplace

The **Marketplace** is a catalogue of ready-made, reusable data-quality rules —
so you don't have to write the common ones from scratch. Browse rules grouped by
domain, tick the ones you want, and import them into your Rules Registry as
reusable templates you can map onto your tables.

<Admonition type="info" title="Admin only">
The Marketplace is available to workspace **admins**. Find it in the sidebar,
just above **Documentation**.
</Admonition>

## Browse, preview, and import

Rules are grouped into **domain packs** — Contacts & People, Addresses & Geo,
Pricing & Money, and more. Two filters narrow what's shown: **Industry** (e.g.
Banking, Retail, Healthcare) and **Region** (hierarchical — choosing **EU** shows
every EU rule, choosing **France** narrows to that country). The **search** box
finds a rule by name across every pack.

Click a rule to expand it and see exactly what it does — its logic, parameters,
and whether the row passes or fails when the condition is true. Not sure a rule
behaves as you expect? Hit **Try it out** to open a test panel, type a few sample
values (or point at one of your tables), and see per-row pass/fail before you
import anything.

Tick the rules you want — individually, or a whole pack via its header
checkbox — then click **Import _N_ selected**. They land in your Rules Registry,
ready to [assign to your tables](/docs/studio/monitoring/assign-rules).

<Admonition type="tip" title="Imported rules arrive approved">
Because Marketplace packs are curated and the Marketplace is admin-only, imported
rules are **published on import** — they don't sit in the approval queue.
Re-importing is safe: a rule you already have is reused, not duplicated.
</Admonition>

## Deploy demo content

The Marketplace is also home to **Deploy demo content** — the first row on the
page. It fills the workspace with example tables, rules, and past run results so
you can explore the Studio with realistic data. Click the row, confirm (the
default wipes existing Studio data for a clean slate), and it seeds in the
background — it takes a while, so leave it to run.

## Contribute a pack

The rule packs are DQX-YAML files in the
[DQX repository](https://github.com/databrickslabs/dqx/tree/main/app/src/databricks_labs_dqx_app/backend/marketplace/packs).
To add a rule or a whole new domain pack, open a pull request — see the README in
that directory for the format. There's a **Contribute on GitHub** link in the
Marketplace header too.
